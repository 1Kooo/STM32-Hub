# STM32-Hub

STM32 常用外设驱动与函数封装集合，**标准外设库（SPL）+ HAL 双版本**。

面向 STM32 嵌入式开发，驱动代码直接拷贝进 Keil 工程即可使用，按需修改头文件里的引脚宏配置。

## 支持平台

| 平台 | 状态 |
|---|---|
| STM32F103C8T6 | ✅ 默认平台 |
| 其他 STM32 系列 | 🚧 待适配 |

## 目录结构

```
STM32-Hub/
├── StdPeriph/      # 标准外设库版本（Keil MDK + SPL）
│   ├── led/        #   LED 驱动
│   └── key/        #   按键驱动
└── HAL/            # HAL 库版本（CubeMX + HAL）
    ├── led/
    └── key/
```

## 收录清单

| 外设 | 说明 | StdPeriph | HAL |
|---|---|---|---|
| LED | 多路 LED 点亮/熄灭/翻转，极性可配 | 🚧 开发中 | 🚧 开发中 |
| 按键 | 上拉输入 + 消抖 + 边沿检测 | 🚧 开发中 | 🚧 开发中 |

## 使用方法

1. 将对应版本的 `.c` / `.h` 文件拷贝进 Keil 工程（如 `StdPeriph/led/`）
2. 在头文件中修改引脚宏配置（端口、引脚号、极性）
3. 在 `main.c` 中调用初始化函数后即可使用

## 代码规范

- 变量命名：小驼峰（如 `curBattery`）
- 函数命名：大驼峰（如 `Led_Init()`）
- 宏/常量：全大写 + 下划线（如 `LED1_PIN`）
- 注释：中文
- 每个 `.c` 配一个 `.h`
